# 🎯 Guess The Number Advanced

A feature-rich number guessing game built using HTML, CSS, and JavaScript.

## 🚀 Features
- 🎮 Difficulty Levels (Easy, Medium, Hard)
- ⏱️ Timer Mode
- 🌗 Dark/Light Theme
- 🏆 High Score Tracking

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
